# JWT Token Storage

This repository contains the code accompanying the [article](https://medium.com/@elie29/frontend-jwt-token-storage-77cbe6dc680b) about where a browser should store a JWT.

It includes two small applications:

- **Backend** — issues JWTs
- **Frontend** — demonstrates how the token can be stored and used in the browser

Each application is a standalone npm project and can be run independently.

## Backend

- Create .env file with TOKEN_SECRET
- `npm i`
- `npm start`

## Frontend

- `npm i`
- `npm start`
